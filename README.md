# 🛍️ NÓMADA — Tienda Online Interactiva

Aplicación frontend de comercio electrónico desarrollada como proyecto de portafolio.

**NÓMADA** presenta una experiencia de compra moderna con catálogo de productos, búsqueda, filtros, favoritos, carrito y un proceso de checkout simulado.

> Este proyecto es una demostración frontend. No procesa pagos reales ni realiza pedidos.

---

## ✨ Funcionalidades

- 🛍️ Catálogo interactivo de productos
- 🔎 Búsqueda de productos
- 🗂️ Filtros por categoría
- ↕️ Ordenamiento por precio y nombre
- ❤️ Sistema de favoritos
- 🛒 Carrito de compras
- ➕ Control de productos en la bolsa
- 💰 Cálculo de subtotal, envío y total
- 🎟️ Código promocional de demostración
- 👁️ Vista detallada de productos
- 🎨 Selección de acabados
- 📦 Indicador de envío gratuito
- 💳 Checkout simulado
- 🚚 Selección de método de entrega
- ✅ Confirmación final de pedido
- 🔔 Notificaciones visuales
- 📱 Interfaz orientada a diferentes tamaños de pantalla

---

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- DOM API
- Formularios HTML
- Diseño responsive

## 🛒 Experiencia de compra

El proyecto simula el flujo principal de una tienda online:

```text
Explorar catálogo
       ↓
Buscar / filtrar productos
       ↓
Ver detalle
       ↓
Agregar al carrito
       ↓
Aplicar promoción
       ↓
Checkout
       ↓
Seleccionar entrega
       ↓
Confirmar pedido
